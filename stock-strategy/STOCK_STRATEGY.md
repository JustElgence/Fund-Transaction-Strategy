# 📈 A股股票购买策略 v1.0

> 定位：**短线/波段（3-15 天）** 为主的个股买入策略，辅以盘面热点轮动选股。
> 数据：腾讯指数 API + 新浪个股涨幅榜 + akshare 技术指标。
> 风险提示：本策略仅为量化框架参考，**不构成投资建议**。

---

## 一、选股流程（每个交易日）

```
采集行情 → 筛掉不合格标的 → 热点板块打分 → 板块内选 TOP3 个股 → 生成买卖点 → 执行与风控
```

1. **采集数据**：运行 `daily_stock_analysis.py`（腾讯指数 + 新浪涨幅榜）。
2. **硬性过滤**：剔除 ST/*ST/退市/N 字头等风险标的。
3. **热点聚类**：把当日活跃个股按板块归类（半导体、AI、CXO/创新药、资源、新能源、军工、券商、消费……），计算板块综合热度。
4. **板块内选股**：取最强板块内涨幅居前、量能健康的个股。
5. **生成交易计划**：给出参考买入区间、止损、分批止盈、仓位。

---

## 二、标的硬性筛选条件（不满足直接排除）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 涨跌幅 | **2% ~ 8%** | 太弱无资金关注；涨停板不追高 |
| 换手率 | **> 1%**（优选 3%~12%） | 有活跃度，避免僵尸股 |
| 成交额 | **> 5000 万**（大票优选 > 3 亿） | 保证流动性 |
| 市值 | **> 20 亿**（优选 50~300 亿） | 市值太小波动失控 |
| 股价 | **> 2 元** | 规避低价仙股 |
| 板块 | 排除已连续涨停/一字板 | 追高风险大 |

> 可按需在 `daily_stock_analysis.py` 的 `screen_stocks()` / `score_stock()` 中调整阈值。

---

## 三、板块热度打分（选方向）

对每个候选板块计算：

- **板块平均涨幅**（权重最高）
- **涨停/大涨股数量加分**
- **成交额放大程度**（资金关注度）

综合得分最高的 **TOP3 板块** 即为当日主攻方向，随市场轮动每日不同。

---

## 四、个股综合打分模型

对板块内个股打分（择优录取）：

| 维度 | 满分 | 规则 |
|------|:----:|------|
| 涨幅位置 | 30 | 3%~5.5% 最佳；过低说明弱，过高说明过热 |
| 换手率 | 25 | 3%~12% 最健康 |
| 成交额 | 25 | >10 亿得满分，>3 亿次之 |
| 市值 | 15 | 50~300 亿最优 |
| 板块属性 | 5 | 主板/北交所优先（可配置是否排除科创/创业板） |

## 五、买入策略（择时）

| 股票状态 | 建议动作 |
|----------|----------|
| 涨幅 ≤ 4%，震荡刚启动 | **现价附近分仓布局**（首批 30%~40%） |
| 涨幅 4%~6%，偏强整理 | **现价附近参与，或等微调** |
| 涨幅 > 6%，强势上攻 | **不追高，等回踩 5 日线低吸** |
| 触及布林下轨 + RSI<30 | 超跌反弹买点，可加仓 |
| 放量突破 20 日新高 | 趋势突破买点 |

**参考买入区间**：现价 × 0.97 ~ 现价 × 1.02（回踩不破位则有效）。

## 六、仓位管理

- **单只个股仓位上限 = 20%**（高弹性题材股 ≤ 15%）。
- **同时持有 ≤ 5 只**，分散但不散乱。
- **总仓位随大盘情绪调整**：

| 大盘情绪 | 均涨幅 | 建议总仓位 |
|----------|--------|-----------|
| 偏弱 | < -0.5% | 3 成以下 |
| 震荡 | -0.5% ~ +0.3% | 3~5 成 |
| 偏强 | > +0.3% | 5~7 成 |

- 现金永远 ≥ 20%（留足子弹，永不满仓）。

## 七、风控（保命条款）

### 单笔止损 / 止盈

| 项目 | 规则 |
|------|------|
| 🛡️ 固定止损 | 买入价 **-7%**（严格纪律，触及即走） |
| 🛡️ 趋势止损 | 跌破 **MA20** 减仓、跌破 **MA60** 清仓 |
| 💰 止盈 T1 | **+5%**（减 1/3） |
| 💰 止盈 T2 | **+8%**（减 1/3） |
| 💰 止盈 T3 | **+12%**（剩余仓移动止盈） |
| 📈 移动止盈 | 盈利 10%+ 后，回撤 **5%** 减仓 / **10%** 清仓 |

### 纪律红线

- ❌ 不追涨停板、不接一字板；
- ❌ 不在亏损单上加仓摊薄；
- ❌ 连续 2 次止损后，强制休息 3 个交易日；
- ❌ 单日振幅 > 5% 的票不追（波动过大）。

## 八、监控预警（持仓期）

持仓后可用 `skills-reference/stock-monitor_SKILL.md` 中的 **7 大预警规则** 盯盘：

1. 成本百分比（盈利 +15% / 亏损 -12% 提醒）
2. 日内涨跌幅（个股 ±4%）
3. 成交量异动（放量 >2 倍 / 缩量 <0.5 倍）
4. 均线金叉/死叉（MA5 上穿/下穿 MA10）
5. RSI 超买超卖（>70 / <30）
6. 跳空缺口（>1%）
7. 动态止盈（盈利 10% 后回撤 5%/10%）

**多条件共振 = 紧急信号**；单一信号 = 提醒级，仅作参考。
