# 技术指标解读参考

## 均线系统 (MA)

| 排列形态 | 含义 | 策略 |
|---------|------|------|
| 多头排列 (MA5>MA10>MA20>MA60) | 上升趋势，强势 | 持股或逢回踩均线买入 |
| 空头排列 (MA5<MA10<MA20<MA60) | 下降趋势，弱势 | 观望或反弹减仓 |
| 粘合/交叉 | 方向选择中 | 等待方向明确，金叉做多、死叉做空 |
| MA5上穿MA10 | 短线金叉 | 短线买入信号 |
| MA5下穿MA10 | 短线死叉 | 短线卖出信号 |
| 价格回踩MA20不破 | 中线支撑有效 | 中线加仓点 |
| 价格跌破MA60 | 趋势可能转空 | 减仓/止损 |

## RSI (相对强弱指标)

| 区间 | 含义 | 策略 |
|:----:|------|------|
| RSI > 80 | 严重超买⚠️ | 注意回调风险，可减仓 |
| RSI 70-80 | 超买区域 | 不宜追高，部分止盈 |
| RSI 50-70 | 偏强区间 | 趋势良好，持股为主 |
| RSI 30-50 | 偏弱区间 | 弱势整理，观望 |
| RSI < 30 | 超卖区域💡 | 可能反弹，关注 |
| RSI < 20 | 严重超卖 | 反弹概率大，可考虑轻仓试探 |

## MACD

| 状态 | 含义 | 策略 |
|:----:|------|------|
| DIF > DEA (金叉) | 多头信号 | 买入/持股 |
| DIF < DEA (死叉) | 空头信号 | 卖出/观望 |
| DIF在零轴上方 | 多头市场 | 机会大于风险 |
| DIF在零轴下方 | 空头市场 | 风险大于机会 |
| MACD柱由负转正 | 动能转强 | 买入信号 |
| MACD柱由正转负 | 动能转弱 | 卖出信号 |
| 底背离 (价新低, MACD未新低) | 下跌衰竭 | 可能见底反弹 |
| 顶背离 (价新高, MACD未新高) | 上涨乏力 | 可能见顶回落 |

## 布林带 (Bollinger Bands)

| 位置 | 含义 | 策略 |
|:----:|------|------|
| 触及/突破上轨 | 超买或强势趋势 | 趋势股可持有，震荡股可止盈 |
| 中轨上方运行 | 偏强 | 持股为主 |
| 中轨下方运行 | 偏弱 | 观望 |
| 触及/跌破下轨 | 超卖或恐慌杀跌 | 关注反弹机会 |
| 布林带收窄(缩口) | 变盘前兆 | 准备突破方向确认 |
| 布林带扩张(开口) | 趋势加速 | 顺势操作 |

## 成交量

| 形态 | 含义 | 策略 |
|:----:|------|------|
| 价涨量增 | 健康上涨 | 持股 |
| 价涨量缩 | 上涨乏力 | 注意回调 |
| 价跌量增 | 恐慌抛售或主力出货 | 减仓观望 |
| 价跌量缩 | 缩量下跌/洗盘 | 关注止跌信号 |
| 底部放量 | 资金入场 | 可能见底 |
| 高位放量滞涨 | 出货嫌疑 | 减仓 |
| 5日均量 > 20日均量1.5倍+ | 显著放量📊 | 趋势确认 |
| 5日均量 < 20日均量0.7倍 | 缩量整理📉 | 方向选择前 |

## ATR (平均真实波幅)

| ATR% | 波动分类 | 止损参考 |
|:----:|---------|:--------:|
| < 2% | 低波动 | 1.5×ATR |
| 2-4% | 中波动 | 2×ATR |
| 4-8% | 高波动 | 2.5×ATR |
| > 8% | 极高波动 | 3×ATR 或固定百分比 |

## 综合趋势评分

| 分数区间 | 评级 | 建议 |
|:-------:|:----:|:----|
| 85-100 | 极强📈 | 重仓/积极做多 |
| 65-84 | 偏强📈 | 中等仓位/趋势跟随 |
| 35-64 | 中性➡️ | 轻仓或观望 |
| 15-34 | 偏弱📉 | 减仓/谨慎 |
| 0-14 | 极弱📉 | 空仓/回避 |

## 财务指标健康标准

| 指标 | 优秀 | 良好 | 一般 | 较差 |
|:----:|:---:|:---:|:---:|:---:|
| ROE | >20% | 15-20% | 8-15% | <8% |
| 毛利率 | >50% | 30-50% | 15-30% | <15% |
| 营收增长率 | >30% | 15-30% | 5-15% | <5% |
| 净利润增长率 | >30% | 15-30% | 5-15% | <5% |
| 资产负债率 | <30% | 30-50% | 50-70% | >70% |
| PE(TTM) | — | 15-25x | 25-40x | >40x或亏损 |
