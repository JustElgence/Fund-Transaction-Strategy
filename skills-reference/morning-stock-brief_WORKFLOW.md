# 📊 每日A股分析报告 Workflow

当用户询问"今天该买什么股票"或类似问题时，按以下流程执行：

## 数据采集

```bash
cd ~/.openclaw/workspace/skills/morning-stock-brief/scripts
python3 fetch_data.py
```

## 新闻采集

```bash
# CLS telegraph
web_fetch url="https://www.cls.cn/telegraph" maxChars=8000
```

## 报告生成流程

### 1️⃣ 大盘概况
从 `fetch_data.py` 输出获取 indices 数据。
关键指标：上证指数、深证成指、创业板指、科创50、沪深300、上证50
标注涨跌方向（📈/📉）。

### 2️⃣ 今日重大催化事件
从CLS电报提取，重点关注：
- 政策面（政治局会议、部委政策）
- 行业催化（涨价、订单、项目开工）
- 国际市场变化
- 爆点新闻

### 3️⃣ 五大热点板块
从 `hot_stocks` 数据聚类分析，按板块归类：
- **算力租赁/AI** 💻：行云科技、利通电子、三人行、奥飞数据、平治信息等
- **绿电/电力** ⚡：豫能控股、华电能源、金开新能
- **稀土永磁** 🧲：中国稀土、中稀有色
- **消费/食品** 🥩：妙可蓝多、牧原股份
- **光模块** 📡：兆驰股份、新易盛

每个板块标注核心催化逻辑。

### 4️⃣ 今日 TOP 3 推荐
筛选原则：
1. **非涨停**（涨幅 < 9% 优先，涨停板不推荐追入）
2. **板块核心逻辑强**（有持续催化）
3. **成交活跃**（换手率 > 3%，金额 > 3亿）
4. **PE合理**（优先非亏损股）

推荐格式（每只股票）：

```
### 🥇 股票名 (代码) — 板块名
**当前价**：¥XX.XX｜涨幅 +X.XX%｜换手 X.XX%｜成交 X.XX亿

🔥 推荐理由：（核心催化逻辑）

📋 交易策略：
| 项目 | 内容 |
| 建议类型 | 回调低吸 / 突破买入 |
| 参考价位 | ¥XX-XX（回踩均线附近） |

🛡️ 止损止盈：
| 类型 | 价位 | 说明 |
| 严格止损 | ¥XX.XX | 跌破XX |
| 目标① | ¥XX（+5%） | 第一止盈 |
| 目标② | ¥XX（+10%） | 第二止盈 |
| 仓位建议 | 30-40% | 根据弹性调整 |
```

## 输出规范
- QQ/微信通道：用列表和简洁文字（不用表格时用●-分隔）
- 每个推荐附止损止盈
- 末尾加⚠️免责声明
