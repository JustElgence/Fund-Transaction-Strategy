# 📊 每日盘面分析报告 - daily-stock-report v2.0

## 概述

当用户要求"出今日分析报告"或类似请求时，按以下标准化流程生成。

**核心特性**：
- ✅ **动态选股** — 不再硬编码固定股票，根据市场实时涨幅数据自动选取当日最强3大热点方向
- ✅ **板块轮动识别** — 覆盖半导体、AI/光通信、卫星互联网、有色资源、新能源、机器人、低空经济、消费、医药等12+行业
- ✅ **每只个股完整技术指标** — 入场策略、止损位（2倍ATR/破MA20/固定5%）、止盈目标（5%/8%/12%）、移动止盈起点、仓位建议、风险等级
- ✅ **科创板+创业板排除** — 推荐的9只个股自动过滤科创板（688开头）和创业板（300/301开头）股票，仅从沪深主板和北交所中选取

## 工作流程

### 第一步：采集数据 & 动态选股

```bash
python3 ~/.openclaw/workspace/skills/daily-stock-report/scripts/fetch_market_data.py
```

**动态选股逻辑（v2.2 升级）：**
1. 从覆盖12大行业的 **150+候选股池** 中批量获取实时行情（含板块标签）
2. **自动过滤科创板（688开头）和创业板（300/301开头）股票**，确保推荐个股仅从主板和北交所中选取
3. 按板块计算平均涨幅，叠加涨停/大涨股加分，生成 **板块综合得分**
4. 选取综合得分最高的 **TOP3热点板块**
5. 每个板块内选取涨幅 **TOP3非科创板、非创业板个股**（共9只），自动适应当日市场轮动

输出JSON含：大盘指数、涨幅榜、动态TOP3板块及个股、9只推荐股的完整技术指标。

> 💡 如需调整过滤规则，修改 `fetch_market_data.py` 中 `pick_hot_sectors_and_stocks()` 的参数：
> - `exclude_star_market`（默认 `True`）= 排除科创板（688开头）
> - `exclude_chi_next`（默认 `True`）= 排除创业板（300/301开头）

### 第二步：获取新闻热点

```python
web_fetch("https://finance.eastmoney.com/a/czqyw.html")
```
提取热门新闻标题，识别当日核心催化事件。

### 第三步：生成TOP3个股推荐（含操作指标）

按以下框架输出：

**热点方向（动态选取，每日不同）：**

示例（今日可能是）：
- 🔬 半导体/芯片 — 中芯国际、兆易创新、通富微电
- 🛰 卫星互联网 — 中国卫星、中科星图、电科蓝天
- ⛏ 有色/资源 — 兴业银锡、锡业股份、华锡有色

也可能根据市场轮动变为：
- 🤖 机器人 — 绿的谐波、汇川技术、拓斯达
- 💡 AI/光通信 — 中际旭创、新易盛、光库科技
- 🏭 低空经济 — 万丰奥威、中信海直、纵横股份

每只个股使用 `tech_analysis` 数据，输出完整指标。
