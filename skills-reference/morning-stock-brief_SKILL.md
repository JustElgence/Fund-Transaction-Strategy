# 📊 早盘简报系统 (Morning Stock Brief)

## 功能概述

这是一个全自动的早盘简报生成系统，整合了多个现有技能：

1. **新闻聚合** (news-aggregator) - 获取财经热点
2. **板块分析** (akshare-stock) - 分析热门板块
3. **股票筛选** (akshare-stock) - 筛选值得关注的股票
4. **策略生成** (stock-monitor分析逻辑) - 生成购买策略和止损止盈位

## 工作流程

```
每天早上8点前自动执行:
┌─────────────────┐
│  1. 搜集新闻     │ ← 财经新闻、行业研报
└────────┬────────┘
         ▼
┌─────────────────┐
│  2. 分析板块     │ ← 行业板块、概念板块涨幅排行
└────────┬────────┘
         ▼
┌─────────────────┐
│  3. 市场概况     │ ← 大盘指数、涨跌家数统计
└────────┬────────┘
         ▼
┌─────────────────┐
│  4. 筛选股票     │ ← 基于涨幅、换手率、成交额等指标
└────────┬────────┘
         ▼
┌─────────────────┐
│  5. 生成策略     │ ← 技术指标分析、止损止盈计算
└────────┬────────┘
         ▼
┌─────────────────┐
│  6. 发送简报     │ ← 汇总报告推送给用户
└─────────────────┘
```

## 筛选条件

系统筛选股票时综合考虑：

- ✅ 非ST股票
- ✅ 涨幅 2%-8%（避免涨停追高风险和弱势股）
- ✅ 换手率 > 1%（有活跃度）
- ✅ 成交额 > 5000万（有流动性）

## 策略指标

每只关注股票包含：

| 指标 | 说明 |
|------|------|
| **趋势状态** | 多头排列/空头排列/震荡整理 |
| **RSI** | 超买超卖判断 |
| **入场策略** | 回踩买入/突破买入/观望 |
| **止损位** | 2倍ATR止损 / MA20支撑 / 5%固定止损 |
| **止盈目标** | 5% / 8% / 12% 分阶段止盈 |
| **仓位建议** | 根据风险等级给出建议 |
| **风险等级** | 高/中/中低/中高 |

## 使用方法

### 手动执行

```bash
cd ~/.openclaw/workspace/skills/morning-stock-brief/scripts
python3 generate_brief.py
```

### 定时自动执行

添加crontab任务（每天早上7:30执行）：

```bash
# 编辑crontab
crontab -e

# 添加以下行
30 7 * * 1-5 /root/.openclaw/workspace/skills/morning-stock-brief/scripts/run_brief.sh
```

### 查看报告

```bash
# 查看最新简报
cat ~/.openclaw/workspace/skills/morning-stock-brief/reports/brief_$(date +%Y-%m-%d).md

# 或运行发送脚本
python3 ~/.openclaw/workspace/skills/morning-stock-brief/scripts/send_brief.py
```
