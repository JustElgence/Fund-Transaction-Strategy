# 股票深度分析 Skill

## 📋 概述

对指定的A股个股生成**AI深度分析报告**，覆盖8大分析维度：

| 维度 | 内容 | 数据来源 |
|------|------|---------|
| ① 公司概览 | 代码、名称、市值、市盈率、行业归属 | `fetch_deep_data.py` |
| ② 财务深度 | 营收/利润趋势、ROE、毛利率、增长率 | akshare / tushare |
| ③ 技术面分析 | 均线排列、RSI、MACD、布林带、成交量异动、支撑阻力 | akshare K线计算 |
| ④ 行业地位 | 所属板块、板块热度、同业估值对比 | akshare 行业板块 |
| ⑤ 资金面 | 主力资金流向、大单动向、龙虎榜 | akshare 资金流 |
| ⑥ 新闻催化剂 | 近期重大新闻、研报观点、政策催化 | web_search |
| ⑦ 风险评估 | 宏观/行业/个股风险三维度 | 综合分析 |
| ⑧ 综合策略 | 趋势评分、风险等级、入场/止损/止盈、仓位建议 | 多因子加权 |

---

## 🚀 快速使用

### 步骤1：采集数据

```bash
cd ~/.openclaw/workspace/skills/stock-deep-analysis/scripts
python3 fetch_deep_data.py <股票代码>
```

**参数说明：**
- `<股票代码>` — 纯数字（如 `600519`）或 Tushare 格式（如 `000001.SZ`）
- `--market sh|sz|bj` — 指定市场（自动检测，一般不需要）
- `--tushare-token <TOKEN>` — 可选，提供 Tushare Pro token 获取更全财务数据

**示例：**
```bash
python3 fetch_deep_data.py 600519               # 贵州茅台
python3 fetch_deep_data.py 300750               # 宁德时代
python3 fetch_deep_data.py 000001.SZ --tushare-token xxxxx  # 平安银行 + Tushare
```

### 步骤2：搜索新闻催化剂

```python
web_search(f"{股票名称} {股票代码} 最新新闻 2026")
web_search(f"{股票名称} 研报 评级 目标价")
web_search(f"{股票所属行业} 行业政策 最新动态")
```

### 步骤3：生成深度分析报告

按下方 **报告模板** 结构，使用采集到的数据逐维度生成分析。

## 💡 最佳实践

### 针对不同类型股票的侧重

| 股票类型 | 侧重维度 | 策略偏好 |
|---------|---------|---------|
| **蓝筹白马** (茅台/平安/招行) | 财务、估值、ROE | 低吸、中长线持有 |
| **科技成长** (宁德/中芯/比亚迪) | 行业趋势、增速、研发投入 | 趋势跟踪、波段操作 |
| **周期股** (有色/钢铁/化工) | 商品价格、库存周期、供需 | 顺周期入场、逆周期回避 |
| **题材概念** (AI/机器人/低空) | 政策催化、情绪、资金流 | 快进快出、止损严格 |
| **困境反转** (地产/消费) | 政策拐点、毛利率修复、负债率 | 分批建仓、耐心等待 |
